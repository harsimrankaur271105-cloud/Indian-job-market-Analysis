# 🇮🇳 Indian Job Market Analysis

## 📌 Project Overview

Indian Job Market Analysis is a data analytics and Streamlit-based web application that explores job opportunities and trends in the Indian job market.

The project analyzes job listings based on job roles, companies, locations, skills, experience levels, and salary information.

## 🎯 Objectives

- Analyze the Indian job market using real job listing data
- Explore popular job roles and companies
- Analyze job locations and experience levels
- Understand salary patterns
- Identify frequently occurring skills
- Provide an interactive dashboard for exploring job-market data

## 🛠️ Technologies Used

- Python
- Pandas
- Streamlit
- Data Analysis
- Data Visualization
- CSV Dataset

## 📊 Dataset

The project uses a cleaned Indian job-market dataset containing information such as:

- Job Title
- Company Name
- Location
- Skills
- Experience
- Salary
- Reviews
- Ratings
- Job Description

## 🚀 Application Features

- 🏠 Home page with project overview
- 📊 Interactive job-market dashboard
- 🔎 Job Explorer
- 💼 Job and company analysis
- 📍 Location-based analysis
- 💰 Salary analysis
- 🎯 Experience-level analysis

## 📁 Project Files

- `app.py` – Streamlit application
- `cleaned_indian_job_market.csv` – Cleaned dataset

## ▶️ How to Run

Install the required libraries:

```bash
pip install streamlit pandas
```

Run the application:

```bash
streamlit run app.py
```
