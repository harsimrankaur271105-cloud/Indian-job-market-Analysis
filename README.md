# 🇮🇳 Indian Job Market Analysis

An interactive **Streamlit-based web application** for exploring and analyzing the Indian job market using job listing data.

The project provides insights into **job roles, companies, locations, skills, experience levels, salary information, and career opportunities**.

## 🚀 Features

### 📊 Dashboard
- Job market overview
- Salary analysis
- Skills analysis
- Company and city insights
- Interactive data exploration

### 🔎 Job Explorer
- Search and explore job listings
- Filter jobs by multiple criteria
- View detailed job information
- Explore opportunities based on salary, skills, experience, location and work mode

### 💼 Career Insights
- Role-based career analysis
- Salary insights
- Experience-level analysis
- Companies hiring
- In-demand skills
- Matching job opportunities

### 🤖 Smart Career Tools
- Job recommendations based on user preferences
- Skill gap analysis
- Career insights
- Salary-related analysis

## 🛠️ Technologies Used

- Python
- Streamlit
- Pandas
- NumPy
- Matplotlib
- Plotly
- Data Analysis
- Data Visualization

## ▶️ How to Run

Clone the repository and install the required dependencies.

Then run:

```bash
streamlit run app.py
```

The application will open in your browser.

## 🎯 Project Objective

The objective of this project is to analyze the Indian job market and provide an interactive platform for exploring **job opportunities, salary trends, required skills, companies, locations, experience levels, and career insights**.
